# 摄影排单应用修改方案

## 文档目的

本目录记录摄影排单应用后续产品改造方案，供新的实施对话直接使用。实施时应先阅读对应阶段文档，再结合当前代码和工作区状态拆分任务。

## 产品方向

应用从单纯的排单工具，逐步升级为面向摄影师、妆娘和个人工作室的预约与履约管理工具，覆盖：

```text
公开获客 -> 预约登记 -> 档期管理 -> 收款 -> 拍摄准备 -> 拍摄完成 -> 交付 -> 复购
```

## 实施原则

1. 先完成第一阶段，再进入第二阶段；第二阶段依赖第一阶段的订单状态和订单回执能力。
2. 每个阶段都要同时检查前端流程、后端接口、数据库实体、权限、异常状态和测试。
3. 保留现有手动录入排单能力。手动排单和公开预约登记都直接进入正常排单，不增加服务者审核环节。
4. 不在阶段实施中顺带改造无关页面或大范围更换视觉风格。
5. 现有工作区的用户改动必须保留，实施前先执行 `git status --short` 并识别无关修改。
